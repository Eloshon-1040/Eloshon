## 2. Writer Learned (formats inconnus)

Une colonne de traduction non-défaut devient `translations.<locale>.<field>`
(`text` / `html` pour `bodyHtml`) ; le parser générique la peuple (`setPath`
imbriqué, provenance `translations.en.title`). L'élue par défaut devient le
champ plat. Test : `name_fr / name_en / description_fr / description_en` →
`title` = Tasse, `translations.en = { title: Mug, bodyHtml: <p>en</p> }`.
