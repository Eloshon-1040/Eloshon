## Canon (`@eloshon/catalog`, additif)

```ts
CanonVariant.priceTiers?: CanonPriceTier[];
CanonPriceTier = {
  minQuantity: number; maxQuantity?: number | null;           // absent = ouvert
  price?: number | null;                                       // prix unitaire absolu du palier
  reduction?: { type: 'amount' | 'percentage'; value: number; taxIncluded?: boolean };
  scope?: { ruleRef?, customerGroupRef?, customerRef?, currency?, country?, storeRef? };  // refs opaques ; absent = tout le monde
  period?: CanonSalePeriod;
};
```

Règle : une ligne qui n'est **ni un palier** (`minQuantity > 1` ou borne
haute) **ni scopée** est le prix / la promo ordinaire (`price` /
`compareAtPrice`), jamais un palier.

## Transform générique `price_tiers`

Chemins par args : `min`, `max` (`emptyValues` = ouvert), `price`,
`reduction { type, value, taxIncluded, typeMap }`, `typed { type, amount,
map }` (un montant dont le sens dépend d'un type — BigCommerce),
`scope { … }`, `period { from, to }`, `requireTierOrScope`. Shopware :
`{ min: quantityStart, max: quantityEnd, price: price.0.gross, scope: { ruleRef:
ruleId, currency: price.0.currencyId } }` (entrée Reference, `verified-live`).
PrestaShop et BigCommerce : args testés sur les lignes réelles / la forme
documentée (`test/price-tiers-c1.test.mjs`) ; leurs entrées Reference
viendront avec leurs parsers.

## Cibles

`loss_<cible>_price_tiers { count, products, handles }` sur les quatre
cibles (FR/EN) ; la variante garde son prix unique ; aucun prix de palier ne
fuit dans une cellule (test).

## C2 — Omnibus : EXT, clos

Shopware seul (`price[].regulationPrice`) ; PrestaShop 9 : aucune colonne ni
réglage ; BigCommerce : `retail_price` / `map_price` ne sont pas un prix
de référence légal ; Wix : rien. `sourceExtension.shopware.price` le garde.

## Limite connue

Un enfant Shopware dont `prices` vaut `[]` n'hérite pas des paliers du parent
(l'héritage déclaré porte sur `null`, pas sur un tableau vide) — aucune
observation d'un parent à variantes **et** à paliers dans les fixtures ;
à traiter à la première observation (`emptyArrayMeansParent`).
