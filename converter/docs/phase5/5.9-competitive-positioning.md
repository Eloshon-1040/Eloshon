# Phase 5.9 — Positionnement concurrentiel (douleurs réelles → capacités livrées)

Sources : avis 1-3★ et sections « cons » (Capterra, Trustpilot, Shopify App
Store), comparatifs d'agences ayant réalisé des migrations. **Aucune page
marketing d'un concurrent** n'a été utilisée. Les citations sont courtes et
attribuées ; ce document alimente la copie eloshon.com (tâche séparée).

## 2. Mapping douleur → capacité Eloshon Converter (livrée, testée)

| Douleur | Capacité concrète | Preuve dans le code |
|---|---|---|
| P1, P11 (données custom aplaties) | **Zéro perte silencieuse** : toute clé source est soit canon, soit `sourceExtension.<plateforme>` (verbatim), soit `unmapped[]` avec raison ; les `meta_data` WC deviennent des metafields ; les colonnes inconnues d'un CSV sont conservées `_raw` + listées | `generic-parser.mjs` ; `parity-contract.test.mjs` (B) ; `generic-parser.test.mjs` « no silent loss » |
| P2 (20 % sautés sans message) | Comptes explicites `inputUnits / outputUnits / failedUnits`, erreurs **par ligne** (`row`, `field`, `code`), pertes et avertissements codés dans chaque résultat ; goldens `*.meta.json` gèlent ce comportement | `index.ts finishProducts` ; `test/golden/*.meta.json` |
| P3 (alt text) | `images[].alt` porté depuis WC REST (`images[].alt`) et jusqu'à `Image Alt Text` Shopify | `woo-rest.test.mjs` (`Image Alt Text = "le logo de levis"`) |
| P4 (HTML aplati) | `description` → `bodyHtml` **verbatim** (`html` transform, jamais nettoyé), gelé dans les canon snapshots | `woo_rest__to_*.canon.json` |
| P5 (prix faux) | Relation prix↔promo explicite : `price` = prix payé, `compareAtPrice` = prix barré, reconstruite depuis `regular/sale/on_sale` (`price_promo`), promo inactive ⇒ pas de barré ; prix absent ⇒ `null`, jamais `0` | `generic-parser.test.mjs` « price/promo edge cases » ; `scraper-formats.test.mjs` (Colruyt) |
| P6 (marque perdue) | `brands` (taxonomie WC 9.6+) → `vendor` ; toutes les marques conservées en `sourceExtension` | `woocommerce.products.rest.v1.json` ; test « brands taxonomy → vendor » |
| P7 (catégories aplaties / fausses) | Hiérarchie **reconstruite** depuis la taxonomie (`category_paths_from_terms`, ancêtres absorbés) → `"Ventilation > Extracteurs"` ; virgules dans un nom de catégorie échappées comme l'exporteur WC (`\,`) | tests « hierarchy rebuilt » ; `roundtrip.test.mjs` (Lidl) |
| P8 (type de produit) | `kind` normalisé (`simple / variable / grouped / external / digital`) + blocs `digital` (downloads, limite, expiration) et `external` (url, bouton) | `woo_rest__to_*.canon.json` ; round-trip synthétique |
| P9 (poids faux) | Unités explicites en données (`weight_to_grams` + `unit`), inférées du nom de colonne pour un format appris, **notées** quand supposées | `transform-aliases.v1.json unitHints` ; test « Poids (kg) → weight_to_grams » |
| P10 (boîte noire) | **Provenance sur chaque valeur** (plateforme, champ source, transform, méthode) ; mapping visible/éditable à l'étape 3 ; candidats avec score et 3 exemples réels | `provenance` dans tous les canon snapshots ; UI étape 3 (`renderMappingTable`, `renderKnowledgeTable`) |
| P16 (vérifier après coup) | Aperçu des lignes converties **avant** export ; contrat analyse↔conversion automatisé : ce que l'écran promet, le fichier le contient | `bindPreview` ; `parity-contract.test.mjs` (A) |
| P17 (rien n'est appris) | **Connaissance apprise** : décisions mémorisées par format ; un CSV inconnu devient un format reconnu (hash structurel) et converti sans code ; les exports Eloshon Scraper sont convertibles nativement | `learn.mjs`, `json-store putLearnedFormat` ; `scraper-formats.test.mjs` ; selftest `learnWalk` |
| P12, P13 (lenteur, coût par entité, refund) | Application **locale**, conversion instantanée (goldens : 463 produits Levi's en < 1 s), pas de facturation par entité ni de « migration des données récentes » payante : on relance le fichier | `directions.mjs` (freeLimit + prix unique) ; architecture (aucun réseau) |
| P14, P15 (accès intrusif, suppressions) | Fichiers en entrée, fichiers en sortie ; aucun accès à la boutique, aucune écriture distante ; les adaptateurs API restent en lecture seule et optionnels (5.8 roadmap) | `app/main.mjs` (« 100 % local ») |

## 3. Douleurs **non** couvertes à ce jour (à dire honnêtement)

| Douleur | État | Piste |
|---|---|---|
| Redirections SEO complexes | Redirections handle→URL générées (`buildRedirects`) pour les produits seulement ; pas d'audit des permaliens catégories/pages | 5.8 API adapters / hors périmètre |
| Images embarquées dans les descriptions (liens vers l'ancien serveur) | Conservées verbatim dans `bodyHtml`, non ré-hébergées | future passe « assets » |
| Avis / notes produits | Pas de champ canon : `average_rating`, `rating_count`, `total_sales` conservés en `sourceExtension` et **listés** `no-canon-field` | décision canon 5.4 |
| > 3 axes d'options vers Shopify | Les attributs descriptifs vont en `attributesRich` / metafields ; au-delà de 3 axes de variation, le sérialiseur Shopify tronque — à rendre explicite comme perte | à ajouter dans `productLossesToShopify` |
| Clients / commandes depuis un format appris | Parser générique = produits ; clients/commandes via parsers CSV existants uniquement | 5.9 (roadmap précédente) |
| Hashes de mots de passe, logique de plugins | Impossible par fichier, comme pour tous | — |

## 4. Axes de message (pour la copie, sans superlatifs invérifiables)

1. **« Rien ne disparaît en silence. »** Chaque champ source finit dans le
   canon, dans une extension nommée, ou dans une liste « non repris » avec la
   raison — visible avant l'export. (P1, P2, P11)
2. **« Le convertisseur comprend la structure, pas seulement les colonnes. »**
   Variantes, options, hiérarchie de catégories, prix/promo, stock par
   variante, produits liés : des relations reconstruites, pas des cellules
   déplacées. (P5, P7, P8)
3. **« Vous voyez d'où vient chaque valeur. »** Provenance par champ, mapping
   éditable, aperçu avant export. (P10, P16)
4. **« Il apprend vos formats. »** Un fichier inconnu se reconnaît une fois ;
   les suivants passent directement. Les exports Eloshon Scraper sont natifs.
   (P17)
5. **« Local, instantané, sans accès à votre boutique. »** (P12, P13, P14, P15)
