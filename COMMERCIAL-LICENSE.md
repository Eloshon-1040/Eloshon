# Usage commercial

Le code de ce dépôt est publié sous **PolyForm Noncommercial 1.0.0** (voir [LICENSE](LICENSE)).

## Ce qui est permis, gratuitement

- usage personnel, loisir, étude, recherche ;
- enseignement et établissements d'enseignement ;
- associations, organisations caritatives et à but non lucratif ;
- institutions publiques ;
- modification et partage du code **pour ces mêmes usages**, en conservant la licence et la mention `Required Notice`.

## Ce qui exige une licence commerciale

Tout usage dans un cadre commercial, par exemple :

- utiliser le logiciel pour les besoins d'une entreprise, d'une boutique en ligne ou d'une activité rémunérée (y compris convertir ou collecter le catalogue d'un client) ;
- le vendre, le louer, l'héberger en service payant ou l'intégrer à un produit ou service payant ;
- le redistribuer dans une offre commerciale.

Pour obtenir une licence commerciale, écrivez à **team@eloshon.com** en décrivant votre usage.
